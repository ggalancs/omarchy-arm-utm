# Every function and variable name declared in this repository, reviewed once
# and committed.
#
# Neither the comment scan nor the string scan ever looked at identifiers, so
# `cargar_respuestas`, `cuestionario`, `montar`, `vigilar`, `PUNTO`, `RAIZ` and
# fifteen more survived pass after pass that reported zero. Morphology cannot
# help here: identifiers are short words, and `montar` and `PUNTO` carry no
# shape a rule could catch.
#
# So this is a ledger, not a detector. A name that is not in this file is
# reported, which forces a decision on every new identifier rather than hoping
# a heuristic notices. Adding one is a line in a diff somebody reads.
